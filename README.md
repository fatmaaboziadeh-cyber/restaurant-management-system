## 🎯 السيناريو البرمجي والميزات الحالية

### 🔹 أولاً: واجهة المستخدم والزبائن (Client Side)
1. **قائمة الطعام التفاعلية (`index.php`):** عرض فوري ومنسق لكافة الوجبات، المأكولات، والمشروبات المتاحة في المطعم.
2. **نظام الطلب المباشر:** بمجرد اختيار الوجبة، يتيح النظام للزبون إدخال بياناته الشخصية الأساسية:
   * *اسم الزبون الكامل*
   * *رقم الهاتف للتواصل*
   * *عنوان التوصيل بدقة*

### 🔹 ثانياً: لوحة تحكم الإدارة (Admin Dashboard)
* **بوابة الأمان والحماية (`admin.php` & `login.php`):** حظر دخول أي مستخدم غير مصرح له، وتحويله تلقائياً لصفحة تسجيل الدخول لحماية البيانات.
* **شاشة العرض المركزية للطلبات (`view_orders.php`):** تم بناء استعلام SQL ذكي ومتقدم يعتمد على خاصية الربط **`LEFT JOIN`** للربط بين ثلاثة جداول أساسية وهي:
  $$\text{orders} \longleftrightarrow \text{order\_details} \longleftrightarrow \text{menu\_items}$$
* **تفاصيل الجدول الإداري:** يعرض الجدول الحسابات بشكل منسق يشمل:
  * _رقم معرف الطلب الفرعي والآلي_
  * _اسم الوجبة المطلوبة بدقة (برجر، بيتزا، مشروبات... إلخ)_
  * _الكمية المطلوبة والسعر الفرعي لكل وجبة_
  * _بيانات الزبون وعنوانه بالكامل مع الحساب الإجمالي ووقت وتاريخ الطلب الفعلي_

## 📁 الهيكل التنظيمي لملفات المشروع (Directory Structure)

* 📄 `index.php` ── الواجهة الرئيسية لعرض قائمة طعام مطعم لو غستو للزبائن.
* 📄 `db.php` ── حجر الأساس المسؤول عن الاتصال الآمن والربط بقاعدة بيانات السيرفر المحلي.
* 📄 `login.php` ── شاشة التحقق من بيانات الأدمن لتسجيل الدخول بأمان.
* 📄 `admin.php` ── ملف الحماية والتوجيه التلقائي الذكي لبوابة الإدارة.
* 📄 `view_orders.php` ── لوحة التحكم الفخمة والمسؤولة عن جلب وعرض تفاصيل الطلبات والوجبات.
